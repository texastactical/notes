# 🎯 Projects

Active efforts with a **defined goal** and a **finish line**. Keep this list short — when something is done, move it to [[04 Archive/Archive|Archive]].

## Active
_None yet. Create a project with the Project template (`templates/Project Template`)._

> [!tip] What counts as a project?
> A project has an outcome you can mark "done" (e.g. *"Launch the notes site"*), unlike an [[02 Areas/Areas|Area]], which you simply maintain (e.g. *"Finances"*).
